# Career Service Exam (CSE) Guide — March 2027

Static, responsive recreation of the provided Notion page design.

## Files

- `index.html` — page structure and card links
- `styles.css` — responsive styling
- `script.js` — lightweight JavaScript placeholder
- `assets/` — image assets cropped from the supplied screenshot

## GitHub Pages

1. Upload the entire folder contents to a GitHub repository.
2. In GitHub, open **Settings → Pages**.
3. Select **Deploy from a branch**, choose the branch containing these files, and select `/ (root)`.
4. Save. GitHub will publish the site.

## Editing the card destinations

In `index.html`, change the `href` values on the four cards from `#mag-take`, `#eserve`, `#requirements`, and `#faqs` to the URLs/pages you want each card to open.
